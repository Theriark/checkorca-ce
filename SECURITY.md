## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately with GitHub private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Only the maintainers can read the report. Include the affected file or component, the steps to reproduce, and the impact you expect.

Do not include real client data, credentials or secrets in a report. Use synthetic values such as `example.com` addresses and `192.0.2.0/24` IP addresses.

If the Report a vulnerability option is not shown, open a public issue that asks for a private contact route and contains no technical detail.
